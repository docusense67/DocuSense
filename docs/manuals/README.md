# User manuals

Guides for the people who use the Academic Document System day to day.

| Guide | For |
| --- | --- |
| [Student quick guide](student-quick-guide.md) | Students: request, track and download a TOR or COE. |
| [Teacher guide](teacher-guide.md) | Teachers: encode or upload grades, submit them, and request corrections after the term is locked. |
| [Registrar guide](registrar-guide.md) | Registrar staff: approve requests, manage students, academic setup and grade changes, lock terms, manage templates, read the dashboard and audit trail. |
| [Scan operator guide](operator-guide.md) | Registrar staff with scan operator permission: run the Scan station screen and read VALID / INVALID / NEEDS REVIEW results. |
| [System admin guide](admin-guide.md) | System admins: create staff accounts, unlock and reset accounts, register scan stations, read the overview and audit trail. |
